# 성경 타자 · 암송 — 프로젝트 기획서

## 1. 개요

- **프로그램 목적**: 사용자가 성경 말씀을 타이핑하면서 자연스럽게 암기하도록 돕는다.
- **모방 대상**: 일반적인 "타자연습" 서비스의 UX(문장 제시 → 입력 → 오타 대조 → 채점)를 성경 암송에 맞게 재구성한다.
- **형태**: 별도 서버 없이 브라우저에서 동작하는 정적 웹앱(PWA). 설치 후 오프라인에서도 사용 가능.

## 2. 핵심 기능

### 2.1 본문 선택
- 권(창세기~요한계시록) → 장 선택 시, 시작 절은 1로, 끝 절은 해당 장의 마지막 절로 자동 채워짐.
- "절 범위 선택" 버튼을 누르면 해당 장의 절 번호가 그리드로 뜨는 모달이 열리고, 탭으로 시작·끝 절을 고를 수 있음(숫자 직접 입력 대신 — 모바일에서 숫자 입력이 불편하다는 피드백으로 변경). 범위 밖의 절을 탭하면 그쪽으로 범위가 넓어지고, 범위 안(경계 포함)을 탭하면 그 절 하나로 다시 시작. "전체 선택"으로 장 전체를 바로 고를 수도 있음.

### 2.2 연습 모드 (3종, 동시 조합 가능)
| 모드 | 동작 |
|---|---|
| 무작위 | 선택 범위의 절 순서를 섞음. 이미 입력한 답은 유지됨 |
| 암기모드 | 본문을 가리고 절 번호만 표시. 켜면 오타표시가 자동으로 꺼짐 |
| 오타표시 | 입력한 글자를 원문과 실시간으로 대조해 틀린 글자를 빨간색으로 표시 |

### 2.3 진행 & 채점
- 진행도 표시(n/총 개수), 이전·다음 버튼, `Enter`로 다음 절 이동, `Shift+Enter`로 줄바꿈.
- 절마다 입력값은 메모리에 저장되어 이전 절로 돌아가도 유지됨.
- 암기모드에서 마지막 절을 마치면 전체 채점 모달을 띄워 절마다 정답과 사용자 입력을 글자 단위로 비교.

### 2.4 환경설정 (⚙️ 메뉴)
- 글꼴 선택: 기본 고딕 / 명조체 / 코딩체
- 다크모드 (localStorage 저장)
- 전체화면 토글
- 성구 글자 크기 슬라이더 (14px~45px, localStorage 저장)

### 2.5 사용법 안내
- **도움말 모달**: 설정 메뉴의 "도움말 보기" 버튼으로 열람. 시작 방법·모드 설명·채점·설정·오프라인 사용법을 앱 내부(오프라인)에서 확인 가능.
- **첫 방문 튜토리얼**: 최초 접속 시 화면 요소(본문 선택 → 절 범위 → 모드 → 입력창 → 이동 → 설정)를 순서대로 스포트라이트로 짚어주는 코치마크형 안내. `localStorage`의 `tutorialSeen` 값으로 1회만 자동 노출되며, 도움말 모달의 "사용법 둘러보기" 버튼으로 언제든 재실행 가능.

### 2.6 말씀 듣기 (TTS)
- 브라우저 내장 `speechSynthesis` API만 사용(외부 API 호출 없음).
- 진행도 옆 🔊 버튼으로 현재 절을 한국어 음성으로 재생, 재생 중 재클릭 시 정지.
- 절 이동 시 재생 중인 음성은 자동으로 중단됨.
- 설정 메뉴에서 "듣기 목소리"를 선택할 수 있음. 기기/브라우저에 설치된 한국어 음성 목록을 보여주고(없으면 전체 음성 목록), 선택은 localStorage에 저장되어 다음에도 유지됨.
- 음성 엔진이 온라인 음성만 제공하는 환경(예: 일부 데스크톱 브라우저)에서는 오프라인 상태에서 소리가 안 날 수 있음(알려진 제약, 6장 참고).

#### 2.6.1 고품질 음성 (신경망 TTS, 선택 기능)
- 설정 메뉴의 "🎙️ 고품질 음성" 토글로 켤 수 있는 별도 옵션. 기본은 꺼짐(=기존 `speechSynthesis` 그대로 사용).
- 모델: **MMS-TTS 한국어** ([Xenova/mms-tts-kor](https://huggingface.co/Xenova/mms-tts-kor), 원본 [facebook/mms-tts-kor](https://huggingface.co/facebook/mms-tts-kor), **CC-BY-NC 4.0**, Meta MMS 프로젝트). 브라우저 안에서 [🤗 Transformers.js](https://github.com/xenova/transformers.js)로 100% 로컬 실행(서버 호출 없음).
- **완전히 자체 호스팅**: 라이브러리(`transformers.min.js`)와 WASM 런타임, 모델 파일을 전부 `js/tts/`에 직접 받아서 저장소에 포함(외부 CDN·Hugging Face에 실시간 의존하지 않음). 토글을 켜는 순간에만 이 파일들을 받아오고(최초 1회 약 38MB), 이후엔 브라우저가 캐싱.
- **한글 → 로마자 변환이 핵심 전제조건**: 이 모델은 원문 한글이 아니라 로마자로 변환된 텍스트를 입력으로 기대함(uroman 방식). `app.js`에 순수 JS로 직접 구현한 한글 음절 분해 기반 로마자 변환기(`romanizeKorean`)가 있음 — 표준 로마자 표기법 규칙 기반의 간이 구현이라 uroman의 세부 규칙과 100% 동일하지는 않을 수 있음.
- 문장 하나 생성에 수 초 정도 소요(기기 성능에 따라 다름). 생성 중에는 🔊 버튼이 "⏳"로 바뀜.
- 절 이동/모드 변경 시 재생 중인 신경망 음성도 함께 정지됨(`stopTts()`에서 함께 처리).

### 2.7 음성으로 입력하기 (STT, 보조 입력)
- 브라우저 내장 `SpeechRecognition`(`webkitSpeechRecognition`) API 사용.
- 진행도 옆 🎤 버튼을 눌러 말하면 인식된 텍스트가 입력창에 채워짐(자동 제출 없음 — 사용자가 직접 확인/수정 후 진행). 기존 오타표시·자동저장 로직과 그대로 연동됨.
- **TTS와 달리 완전한 오프라인 기능이 아님** — Chrome/Edge의 음성인식은 서버로 오디오를 보내 처리하므로 인터넷 연결이 필요함.
- **브라우저 지원 제약**: iOS Safari는 미지원 — 해당 환경에서는 버튼이 자동으로 숨겨짐.
- 절 이동 시 진행 중인 인식은 자동으로 중지됨.

### 2.8 오프라인 지원 (PWA)
- `manifest.json` + `sw.js`로 설치형 앱(홈 화면 추가) 및 오프라인 캐싱 지원.
- **캐싱 전략: 네트워크 우선(network-first)**. 온라인이면 항상 서버에서 최신 파일을 받아오고(받아올 때마다 캐시도 같이 갱신), 네트워크 요청이 실패할 때만(오프라인) 캐시로 대체함. 그래서 `sw.js` 자체가 안 바뀌는 일반적인 배포(HTML/CSS/JS만 수정)도 온라인 상태에서 새로고침하면 즉시 반영됨.
- 서비스워커가 오프라인 대비용으로 `index.html`, `css/*`, `js/app.js`, `js/Bible.js`, `manifest.json`, 아이콘 2종을 캐싱.
- **새 버전 알림 배너**: 앱이 포그라운드로 돌아올 때마다(`visibilitychange`) `registration.update()`로 `sw.js` 자체가 바뀌었는지 능동 확인. 새 서비스워커가 제어권을 넘겨받으면(`oncontrollerchange`) 화면 하단에 "🔄 새 버전이 있어요 · 새로고침" 배너 표시. 단, 최초 설치 때도 이 이벤트가 한 번 발생하므로 페이지 로드 시점에 이미 컨트롤러가 있었는지(`hadControllerAtLoad`)로 "최초 설치"와 "재방문 중 갱신"을 구분해 후자일 때만 배너를 띄움. (참고: 이 배너는 `sw.js` 자체의 변경만 감지함 — HTML/CSS/JS 내용 변경은 위의 네트워크 우선 전략 덕분에 배너 없이도 새로고침 한 번이면 바로 반영됨)

## 4. 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 전체 UI 마크업(연습 화면, 채점 모달, 도움말 모달, 튜토리얼 오버레이) |
| `js/app.js` | 앱 로직 전체(본문 로딩, 모드 전환, 채점, 설정, 튜토리얼, TTS) |

| `css/style.css` | 다크모드, 튜토리얼 오버레이 등 커스텀 스타일 |
| `css/tailwind.min.css` | Tailwind 유틸리티 클래스 |
| `manifest.json` | PWA 매니페스트 |
| `js/tts/lib/` | 자체 호스팅한 `transformers.js` 라이브러리 + ONNX Runtime Web WASM 런타임 (고품질 음성 기능용, 토글 켤 때만 로드됨) |
| `js/tts/models/Xenova/mms-tts-kor/` | 자체 호스팅한 MMS-TTS 한국어 모델 파일(config/tokenizer/onnx). CC-BY-NC 4.0, 출처 표시 필요 |

## 5. 기술 스택 / 제약

- 순수 HTML/CSS/JS + Tailwind. 빌드 도구, 프레임워크, 외부 서버 API 없음.
- 브라우저 내장 기능만으로 구현하는 것을 원칙으로 하되, "고품질 음성"(2.6.1)처럼 브라우저 내장 기능만으로는 한계가 있는 경우 **완전히 자체 호스팅한 파일로 브라우저에서만 실행되는 모델**은 예외적으로 허용(런타임에 외부 서버를 호출하지 않으므로 "서버 없음" 원칙은 유지됨).
- **`css/tailwind.min.css`는 Tailwind v2.2.19다.** v2는 `max-h-[80vh]` 같은 임의값(bracket) 문법을 지원하지 않음(v3 JIT부터 지원) — 이런 클래스를 써도 조용히 무시되고 아무 스타일도 적용되지 않는다. 값이 필요하면 `css/style.css`에 `.max-h-modal-80` 같은 이름의 클래스를 직접 정의해서 써야 함(기존 예시 다수 있음).

## 6. 알려진 이슈 / 백로그

- TTS는 브라우저/OS에 따라 온라인 음성만 제공될 수 있어, 오프라인에서 소리가 안 나는 환경이 있을 수 있음.
- (제안 단계) 절·장별 연습 기록(정확도, 연습 횟수, 최근 연습일)을 저장하는 학습 통계 기능 — 아직 미구현.

- 같은 날짜에 여러 번 배포하면 `_01`, `_02`처럼 뒤에 일련번호를 붙여 구분한다 (예: `v0.260914_01`, `v0.260914_02`).

- 도움말 모달 + 첫 방문 코치마크 튜토리얼 추가

- 서비스워커 등록 버그 수정: `sw.js`가 `js/` 폴더 안에 있어 `cache.addAll`이 잘못된 경로(`js/index.html` 등)를 요청해 설치가 조용히 실패하던 문제. `sw.js`를 프로젝트 루트로 옮기고 `app.js`에 `navigator.serviceWorker.register('sw.js')` 등록 코드를 추가해 실제로 오프라인 캐싱이 동작하도록 수정
- `icon-192.png`, `icon-512.png` 추가 (앱 테마색 배경 + ⌨️ 아이콘). `manifest.json`에 512 항목 반영, `sw.js` 캐시 목록에도 포함. PWABuilder 등으로 APK를 만들 때도 512 아이콘이 필요해 함께 준비함

- 음성으로 입력하기(STT) 보조 입력 기능 추가 (`SpeechRecognition` 기반, iOS Safari 미지원·인터넷 필요)
- 절 범위 입력 시 타이핑창으로 포커스가 강제 이동하던 모바일 버그 수정
- 듣기 목소리 선택 기능 추가 (설정 메뉴, 기기별 한국어 음성 목록 중 선택)
- 헤더에 버전 표시(`v0.260914`) 추가

- 버전 표시 `v0.260914_01`로 갱신 (같은 날짜 내 추가 배포 구분용 일련번호 규칙 도입)
- `js/Bible.js`를 `개역한글판성경.txt` 기반으로 재생성해 교체. 기존 데이터의 오류(사무엘상 30장에 실존하지 않는 31절이 `"(없음)"` placeholder로 들어가 있던 문제)가 해결됨
